# 🚀 Семья в космосе — художественный проект

Добро пожаловать в репозиторий истории о семье, которая путешествует в космосе, сталкивается с неизвестными мирами, 
внутренними конфликтами, любовью, утратами и надеждой.

Это литературный проект, который развивается на глазах у читателей. Я публикую главы, наброски и заметки прямо здесь. 
Часть текста может быть изменена или дополнена в будущем.
